List your event on the MyPins map

MyPins is an events map for travellers and expats in Southeast Asia. The map covers three destinations — Bali, Da Nang and Nha Trang — where many travellers and foreigners are looking for things to do: from yoga and markets to concerts and parties. If you run events, this is your audience.

How it works

It all starts with registration: when creating an account you choose the organizer role. Then four steps:

  • Create an event: title, date and time, place on the map, price or “donation”, description and photos. For regular meetups (morning yoga, a weekly quiz) you can set a repeating schedule.
  • Send it to moderation: before publication an administrator reviews the event — this keeps the listings free of spam and duplicates.
  • Get the event page: every event has its own address like mypins.site/en/event/..., which opens in a browser and is indexed by Google.
  • Tell your audience: the short event link is easy to post in a Telegram channel or in stories.

What you get

  • A map, not a feed: an event with a pin, address and date — guests can easily find the venue and get there.
  • An audience that is already looking for events: travellers and expats come to MyPins with searches like “where to go”, “events”, “events for expats”.
  • An organizer page in search: a public profile with a description and the list of your events, indexed by Google. Contacts are shown only if you enable them yourself.
  • Subscribers and notifications: guests subscribe to your profile and receive push notifications about new events.
  • Russian-speaking and English-speaking guests: the interface and event descriptions are available in both languages.

What events can you list

Any offline event people can attend: yoga and retreats, markets and food events, concerts and parties, quizzes and speaking clubs, workshops and lectures, kids' and family formats. The listings are constantly updated and past events are removed — search and the map always show what is current.

Do I need to register to list an event?

Yes. Choose the organizer role during registration — after that event creation and your personal account appear in the interface.

How fast will my event appear on the map?

Events are published after an administrator's review — moderation keeps the listings free of spam and duplicates. If your event is urgent, contact us via the “Contacts” section in the site menu.

My event repeats every week. Is that supported?

Yes. For recurring events you can set a repeating schedule: guests see the nearest date, and the event page stays relevant.

Will English-speaking guests see my event?

Yes. MyPins is bilingual — Russian and English; an event description can be added in both languages, and the interface switches with the button in the header.

Start right now

Open the map and press “Create event” — registration takes a couple of minutes. If you have questions, write to us via the “Contacts” section in the site menu.
