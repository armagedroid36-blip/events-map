7 ноября 2026, 20:00

ΘΟΚ, Никосия, Кипр

Новая сцена Театральной организации Кипра (THOC) представляет пьесу Питера Моргана «Фрост/Никсон» — захватывающую политическую драму, которая переносит на сцену одно из самых знаменитых телевизионных противостояний XX века.
